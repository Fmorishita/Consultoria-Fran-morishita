# Origen de esta skill

Copiada de **taste-skill** (`https://github.com/Leonxlnx/taste-skill`), commit `5217fb4`,
licencia MIT (ver `LICENSE`). Autor: leonxlnx.

- `SKILL.md` = `skills/taste-skill/SKILL.md` del repo original (skill principal de diseño frontend).
- `REDESIGN.md` = `skills/redesign-skill/SKILL.md` (protocolo de rediseño sobre sitios existentes).

El repo original también trae variantes (`brutalist`, `minimalist`, `soft`, `stitch`,
`image-to-code`, `brandkit`) y es además un plugin de Claude Code: se puede instalar
completo con `/plugin marketplace add Leonxlnx/taste-skill`. Aquí se copiaron solo las
dos piezas que aplican a este proyecto.

## Cómo se usó

Se aplicó al sitio `bienesraices/` en la rama `claude/web-supabase-vercel-64zjc4`.
Donde la skill choca con el brief de Fran (`bienesraices/BRIEF.md`), manda el brief:
la skill lo dice explícitamente ("the brand brief overrides").
